# Digital_Design_and_Computer_Architecture
Assignments from the UiO course IN2060

NORSK: Innlevering4er fra UiO. Beskrivelse av faget: "Emnet tar for seg prinsipper i digital design, som kombinatorisk og sekvensiell logikk, tilstandsmaskiner og digitale byggeblokker, og bygger på dette for å introdusere prosessorarkitekturer, pipelining, cache, og grensesnittet mellom maskinvare og programkode."

ENGLISH: Assignments from UiO. Description from website: "The course addresses principles of digital design, such as combinatorial and sequential logic, finite state machines and digital building blocks, and builds on this to introduce processor architectures, pipeline, cache, and the interfaces between hardware and program code."
